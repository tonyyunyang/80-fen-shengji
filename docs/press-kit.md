# Eighty · 八十分 — Press kit

**A free, open-source Chinese partnership card game in your browser.**

**免费开源的经典中国八十分，一张有手感的像素牌桌。**

## Facts

| | |
| --- | --- |
| Name | Eighty · 八十分 |
| Genre | Partnership trick-taking; Shanghai 80-fen / Shengji / Tractor |
| Play | Four seats, two teams; local bots, shared-device humans or optional API models |
| Platform | Desktop browser, with a Node.js 22+ server |
| Price | Free local play; external AI services are optional and may charge separately |

## Short description

**English:** Eighty brings the classic Chinese partnership game of Shengji to a warm pixel table. Two decks, four seats, smooth hand interaction, illustrated cards and free local practice bots. Play in your browser, learn a few new tricks, and help improve the game through open-source contributions.

**中文：** Eighty 把熟悉的八十分带到浏览器里：两副牌、四个座位、两对搭档，还有像素人物、纸质牌面和顺滑的手牌交互。自带免费陪练，支持中文与英文。来打一局，也欢迎用一个 PR 让下一局更好。

## Ready-to-share copy

**English:** A classic card night, now in pixels. Eighty is a free, open-source browser game of Chinese 80-fen / Shengji: hover, select, drag and play with a partner across the table. Local practice bots need no key or subscription. Enjoy the game, star the repo, and send a PR if you'd like to help. PRs are reviewed periodically. https://github.com/tonyyunyang/80-fen-shengji

**中文：** 把八十分搬上一张像素牌桌。Eighty 免费、开源，在浏览器里就能玩；悬停看牌、点选、拖出，和对家一起赢下一局。本地陪练无需 key 或订阅。欢迎试玩、Star、分享给牌友，也欢迎提交 PR；维护者会不定期审核。https://github.com/tonyyunyang/80-fen-shengji
