# 文档 · Documentation

Eighty 是免费开源的八十分浏览器游戏。当前版本 **0.3.0** 加入整组拖牌与街机风格光影特效。The **0.3.0** release combines group dragging with an animated pixel table; the approved table remains the only runtime interface.
