# Roadmap · 下一局的方向

Eighty's current focus is a complete, welcoming card table on desktop and phone. These are directions for discussion, not delivery promises or scheduled releases.

**Available on `main` and the [hosted game](https://eighty.tonytheyang.com/):** selected-group dragging, mobile hand browsing, original background music and phase effects, flowing ink, public scoring effects, optional AI connections and private Cloudflare hosting. See the [changelog](../CHANGELOG.md) and [table behavior](table-experience.md).

| Direction | Useful next contributions |
| --- | --- |
| Card feel / 手感 | More browser/device checks, focus polish, stable hover through live updates. |
| Learning / 学习 | Better first-game explanations, clearer examples of tractors, following and final-trick scoring. |
| Art and sound / 视听 | More original portraits, sound refinements and further device performance checks. |
| AI / 搭档策略 | Stronger whole-deal planning with fair observations, controlled wins/score evaluation and economical action output. |
| Community / 社区 | Natural translations, rules edge cases, useful documentation and accessible controls. |
| Online rooms / 联机 | A future design discussion: room ownership, identity, reconnecting and cross-device privacy. Not implemented today. |

Have a concrete idea? [Open an issue](https://github.com/tonyyunyang/80-fen-shengji/issues/new/choose), or send a focused PR. Maintainers review periodically; there is no fixed release timetable.
