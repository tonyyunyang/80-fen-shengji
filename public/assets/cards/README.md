# Pixel card artwork

`pixel-court.webp` is the approved AI-generated 4×4 atlas used by the single game renderer. Cells 0–11 are J/Q/K for spades, hearts, clubs and diamonds; 12–13 are monochrome/colored jokers; 14–15 are card backs. The game uses the first back consistently.

Ranks and suit glyphs are SVG, assembled with pips and illustrations by `public/card-art.js`. Layout changes do not modify the source atlas.
